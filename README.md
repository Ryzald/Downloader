# Downloader

Alat berbasis HTML untuk mengubah tautan SharePoint/OneDrive menjadi tautan download.

## Penggunaan

1. Buka `indexadvance.html` di browser.
2. Pilih jenis file.
3. Paste tautan SharePoint/OneDrive.
4. Klik **Buat Link Download**.

Hak akses dan kebijakan keamanan Microsoft 365 tetap berlaku.
